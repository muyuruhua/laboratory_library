# test-whiteBox.c 程序说明

## 程序概述

`test-whiteBox.c` 是一个**白盒测试程序**，专门设计用于测试 AFL++ 模糊测试工具的代码覆盖率能力。它包含多个条件分支，适合用于评估模糊测试策略的效果。

## 程序结构

### 主要函数

#### 1. `is_even(int num)` - 判断奇偶性
```c
bool is_even(int num) {
    return (num % 2 == 0);
}
```
- **功能**：判断一个数是否为偶数
- **返回值**：`true` 如果是偶数，`false` 如果是奇数

#### 2. `main()` - 主函数
- **功能**：从标准输入读取两个整数，根据它们的正负性和奇偶性输出不同的情况
- **输入**：两个整数 X 和 Y（用空格分隔）
- **输出**：根据输入的不同组合输出不同的情况说明

## 程序逻辑

### 第一部分：正负性判断（4 种情况）

程序首先根据 X 和 Y 的正负性进行判断：

1. **情况 1**：`X > 0 && Y > 0`
   - 输出："情况1：X 和 Y 都是正数"

2. **情况 2**：`X > 0 && Y <= 0`
   - 输出："情况2：X 是正数，Y 是非正数"

3. **情况 3**：`X <= 0 && Y > 0`
   - 输出："情况3：X 是非正数，Y 是正数"

4. **情况 4**：`X <= 0 && Y <= 0`（else 分支）
   - 输出："情况4：X 和 Y 都是非正数"

### 第二部分：奇偶性判断（4 种情况）

程序然后根据 X 和 Y 的奇偶性进行判断：

1. **附加情况 A**：`x_even && y_even`
   - 输出："附加情况A：X 和 Y 都是偶数"

2. **附加情况 B**：`x_even && !y_even`
   - 输出："附加情况B：X 是偶数，Y 是奇数"

3. **附加情况 C**：`!x_even && y_even`
   - 输出："附加情况C：X 是奇数，Y 是偶数"

4. **附加情况 D**：`!x_even && !y_even`（else 分支）
   - 输出："附加情况D：X 和 Y 都是奇数"

## 控制流图分析

### 基本块和边

程序的控制流包含以下基本块和边：

1. **入口块**：程序开始
2. **输入块**：读取 X 和 Y
3. **正负性判断块**：4 个 if-else 分支
4. **奇偶性计算块**：调用 `is_even()` 函数
5. **奇偶性判断块**：4 个 if-else 分支
6. **输出块**：打印结果
7. **退出块**：返回 0

### 边的数量

根据 AFL++ 的边覆盖率计算方式，这个程序大约有 **17 条边**：

- 入口 → 输入：1 条
- 输入 → 正负性判断：1 条
- 正负性判断的 4 个分支：4 条
- 正负性判断 → 奇偶性计算：1 条
- 奇偶性计算（函数调用）：2 条（进入和退出）
- 奇偶性判断的 4 个分支：4 条
- 各个分支 → 输出：4 条
- 输出 → 退出：1 条

**总计：约 17 条边**

## 为什么选择这个程序？

### 1. 适合测试覆盖率
- 包含多个条件分支
- 不同的输入会触发不同的执行路径
- 容易验证是否覆盖了所有分支

### 2. 适合对比测试
- 程序逻辑简单，执行快速
- 有明确的覆盖率目标（17 条边）
- 可以清楚地看到不同策略的效果

### 3. 白盒测试特性
- 代码可见，可以分析所有可能的路径
- 可以验证模糊测试是否找到了所有分支
- 适合评估模糊测试策略的效率

## 程序执行流程

```
开始
  ↓
读取 X, Y
  ↓
判断 X > 0 && Y > 0?
  ├─ 是 → 输出"情况1"
  ├─ 否 → 判断 X > 0 && Y <= 0?
  │         ├─ 是 → 输出"情况2"
  │         ├─ 否 → 判断 X <= 0 && Y > 0?
  │                   ├─ 是 → 输出"情况3"
  │                   └─ 否 → 输出"情况4"
  ↓
计算 x_even = is_even(X)
计算 y_even = is_even(Y)
  ↓
判断 x_even && y_even?
  ├─ 是 → 输出"附加情况A"
  ├─ 否 → 判断 x_even && !y_even?
  │         ├─ 是 → 输出"附加情况B"
  │         ├─ 否 → 判断 !x_even && y_even?
  │                   ├─ 是 → 输出"附加情况C"
  │                   └─ 否 → 输出"附加情况D"
  ↓
返回 0
```

## 在模糊测试中的作用

### 1. 评估覆盖率能力
- 测试模糊测试工具是否能发现所有 17 条边
- 评估不同策略的覆盖率效率

### 2. 对比测试策略
- 比较原策略和 Lattice-MAB 策略的效果
- 评估哪种策略用更少的执行次数达到相同的覆盖率

### 3. 性能评估
- 测量执行次数、循环数等性能指标
- 评估策略的资源消耗

## 总结

`test-whiteBox.c` 是一个**专门设计的白盒测试程序**，用于：

1. **测试代码覆盖率**：包含多个分支，适合测试覆盖率能力
2. **对比测试策略**：评估不同模糊测试策略的效果
3. **性能评估**：测量执行效率、资源消耗等指标

程序结构简单但包含足够的复杂性，是评估模糊测试策略的理想测试目标。
