# AFL++ 编译和使用指南

## 问题：`afl-cc: command not found`

这个错误表示 AFL++ 还没有编译或者没有安装到系统路径中。

## 解决方案

### 方案 1：编译 AFL++（推荐）

#### 步骤 1：安装依赖（macOS）

```bash
# 安装 Homebrew（如果还没有安装）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装必要的依赖
brew install make llvm cmake python3 git
```

#### 步骤 2：编译 AFL++

```bash
# 进入 AFL++ 目录
cd "/Users/ketangchen/Library/Mobile Documents/com~apple~CloudDocs/Documents/2025laboratory_library/laboratory_library/AFLplusplus-dev"

# 编译基础版本（只编译源代码模糊测试需要的部分）
make source-only

# 或者编译完整版本（包括 QEMU、FRIDA 等模式，需要更多时间）
# make distrib
```

#### 步骤 3：安装到系统（可选）

```bash
# 安装到系统路径（需要 sudo 权限）
sudo make install

# 安装后，afl-cc 就可以在任何地方使用了
```

#### 步骤 4：如果不想安装到系统，使用完整路径

编译完成后，可执行文件会在当前目录下。你可以：

```bash
# 使用完整路径
./afl-cc -o test-instr test-instr.c

# 或者添加到当前 shell 的 PATH
export PATH="$PWD:$PATH"
afl-cc -o test-instr test-instr.c
```

### 方案 2：使用 Docker（最简单，无需编译）

```bash
# 拉取 AFL++ Docker 镜像
docker pull aflplusplus/aflplusplus

# 运行容器，挂载你的代码目录
docker run -ti -v "/Users/ketangchen/Library/Mobile Documents/com~apple~CloudDocs/Documents/2025laboratory_library/laboratory_library/AFLplusplus-dev:/src" aflplusplus/aflplusplus

# 在容器内，你的代码在 /src 目录
cd /src
afl-cc -o test-instr test-instr.c
```

## 使用 test-instr.c 进行模糊测试的完整步骤

### 1. 编译 test-instr.c（使用 AFL++ 编译器）

```bash
# 如果已安装到系统
afl-cc -o test-instr test-instr.c

# 如果使用完整路径
./afl-cc -o test-instr test-instr.c

# 如果使用 Docker
docker run -ti -v "$(pwd):/src" aflplusplus/aflplusplus bash -c "cd /src && afl-cc -o test-instr test-instr.c"
```

### 2. 准备测试种子文件

```bash
mkdir -p seeds
echo "0" > seeds/input1.txt
echo "1" > seeds/input2.txt
```

### 3. 运行模糊测试

```bash
# 创建输出目录
mkdir -p output

# 运行 afl-fuzz
afl-fuzz -i seeds -o output -- ./test-instr

# 如果程序从文件读取输入，使用：
# afl-fuzz -i seeds -o output -- ./test-instr -f @@
```

### 4. 查看结果

- 实时统计界面会显示执行进度
- 崩溃文件保存在：`output/crashes/`
- 超时文件保存在：`output/hangs/`

### 5. 复现崩溃

```bash
# 复现崩溃
cat output/crashes/id:000000,* | ./test-instr

# 使用 gdb 调试
gdb ./test-instr
(gdb) run < output/crashes/id:000000,*
```

## 常见问题

### Q: 编译时提示找不到 gmake
A: macOS 默认的 make 可能不是 GNU make。安装 GNU make：
```bash
brew install make
# 然后使用 gmake 而不是 make
gmake source-only
```

### Q: 编译时提示找不到 llvm
A: 安装 LLVM：
```bash
brew install llvm
# 可能需要设置环境变量
export PATH="/opt/homebrew/opt/llvm/bin:$PATH"
```

### Q: 不想安装到系统，如何永久添加到 PATH？
A: 编辑 `~/.zshrc` 或 `~/.bash_profile`：
```bash
echo 'export PATH="/Users/ketangchen/Library/Mobile Documents/com~apple~CloudDocs/Documents/2025laboratory_library/laboratory_library/AFLplusplus-dev:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

## 验证安装

编译完成后，验证是否成功：

```bash
# 检查可执行文件是否存在
ls -la afl-cc afl-fuzz

# 查看版本信息
./afl-cc --version
./afl-fuzz --version
```
