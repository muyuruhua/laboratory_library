# 代码库多函数模糊测试指南

## 概述

当你想测试代码库中的多个函数时，有几种方法：

1. **持久模式（Persistent Mode）** - 最快的方法，速度可提升 10-20 倍
2. **编写测试工具（Harness）** - 为每个函数或功能模块编写测试工具
3. **使用 libfuzzer 风格的 harness** - 兼容 libfuzzer 的测试接口
4. **测试整个程序** - 如果程序本身可以接受输入

## 方法 1：持久模式（Persistent Mode）- 推荐

持久模式是最快的方法，适合测试库函数或多个函数。它在一个进程中多次调用目标函数，而不是每次都 fork 新进程。

### 适用场景

- 库函数（无状态或可以重置状态）
- 解析函数
- 数据处理函数
- 任何可以重复调用的函数

### 基本模板

创建一个 `fuzz_target.c` 文件：

```c
#include "your_library.h"  // 包含你要测试的库头文件

// 兼容性代码（允许在没有 AFL++ 时编译）
#ifndef __AFL_FUZZ_TESTCASE_LEN
  ssize_t fuzz_len;
  unsigned char fuzz_buf[1024000];
  #define __AFL_FUZZ_TESTCASE_LEN fuzz_len
  #define __AFL_FUZZ_TESTCASE_BUF fuzz_buf
  #define __AFL_FUZZ_INIT() void sync(void);
  #define __AFL_LOOP(x) \
    ((fuzz_len = read(0, fuzz_buf, sizeof(fuzz_buf))) > 0 ? 1 : 0)
  #define __AFL_INIT() sync()
#endif

__AFL_FUZZ_INIT();

int main(int argc, char **argv) {
  
  unsigned char *buf;
  int len;
  
  // 初始化（只执行一次）
  // 例如：初始化库、打开文件等
  // your_library_init();
  
  __AFL_INIT();
  buf = __AFL_FUZZ_TESTCASE_BUF;  // 必须在 __AFL_LOOP 之前赋值！
  
  // 持久模式循环
  while (__AFL_LOOP(10000)) {  // 10000 是最大迭代次数，可根据需要调整
    
    len = __AFL_FUZZ_TESTCASE_LEN;  // 不要直接在函数调用中使用宏！
    
    // 检查最小输入长度
    if (len < 1) continue;
    
    // ========== 在这里调用你要测试的函数 ==========
    
    // 示例 1：测试单个函数
    // your_function(buf, len);
    
    // 示例 2：测试多个函数
    // function1(buf, len);
    // function2(buf, len);
    // function3(buf, len);
    
    // 示例 3：测试函数链
    // result = parse_input(buf, len);
    // if (result) {
    //   process_data(result);
    //   cleanup(result);
    // }
    
    // ============================================
    
    // 重置状态（重要！）
    // 清理内存、重置变量等
    // your_library_reset();
    
  }
  
  return 0;
}
```

### 编译

```bash
# 使用 afl-clang-fast 或 afl-clang-lto（推荐）
./afl-clang-fast -o fuzz_target fuzz_target.c -lyour_library

# 或者使用 afl-cc（会自动选择最佳模式）
./afl-cc -o fuzz_target fuzz_target.c -lyour_library
```

### 运行

```bash
# 准备种子文件
mkdir -p seeds
echo "test input" > seeds/input1.txt

# 运行模糊测试
export AFL_I_DONT_CARE_ABOUT_MISSING_CRASHES=1  # 如果需要
./afl-fuzz -i seeds -o output -- ./fuzz_target
```

## 方法 2：测试多个函数 - 完整示例

假设你有一个库，包含多个解析函数：

```c
// my_library.h
#ifndef MY_LIBRARY_H
#define MY_LIBRARY_H

int parse_json(const char *data, size_t len);
int parse_xml(const char *data, size_t len);
int parse_yaml(const char *data, size_t len);

#endif
```

### 创建测试工具

```c
// fuzz_multi_functions.c
#include "my_library.h"
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#ifndef __AFL_FUZZ_TESTCASE_LEN
  ssize_t fuzz_len;
  unsigned char fuzz_buf[1024000];
  #define __AFL_FUZZ_TESTCASE_LEN fuzz_len
  #define __AFL_FUZZ_TESTCASE_BUF fuzz_buf
  #define __AFL_FUZZ_INIT() void sync(void);
  #define __AFL_LOOP(x) \
    ((fuzz_len = read(0, fuzz_buf, sizeof(fuzz_buf))) > 0 ? 1 : 0)
  #define __AFL_INIT() sync()
#endif

__AFL_FUZZ_INIT();

int main(int argc, char **argv) {
  
  unsigned char *buf;
  int len;
  int result;
  
  __AFL_INIT();
  buf = __AFL_FUZZ_TESTCASE_BUF;
  
  while (__AFL_LOOP(10000)) {
    
    len = __AFL_FUZZ_TESTCASE_LEN;
    
    if (len < 1) continue;
    
    // 测试函数 1：JSON 解析
    result = parse_json((const char *)buf, len);
    // 可以检查结果，但不应该影响后续测试
    
    // 测试函数 2：XML 解析
    result = parse_xml((const char *)buf, len);
    
    // 测试函数 3：YAML 解析
    result = parse_yaml((const char *)buf, len);
    
    // 重置状态（如果有全局状态）
    // reset_parser_state();
    
  }
  
  return 0;
}
```

### 编译和运行

```bash
# 编译库（如果还没有编译）
./afl-cc -c -o my_library.o my_library.c

# 编译测试工具
./afl-cc -o fuzz_multi_functions fuzz_multi_functions.c my_library.o

# 运行
mkdir -p seeds
echo '{"test": "data"}' > seeds/input1.txt
./afl-fuzz -i seeds -o output -- ./fuzz_multi_functions
```

## 方法 3：为不同函数创建独立的测试工具

如果你想要更精细的控制，可以为每个函数创建独立的测试工具：

### 示例：测试 JSON 解析函数

```c
// fuzz_json.c
#include "my_library.h"

#ifndef __AFL_FUZZ_TESTCASE_LEN
  ssize_t fuzz_len;
  unsigned char fuzz_buf[1024000];
  #define __AFL_FUZZ_TESTCASE_LEN fuzz_len
  #define __AFL_FUZZ_TESTCASE_BUF fuzz_buf
  #define __AFL_FUZZ_INIT() void sync(void);
  #define __AFL_LOOP(x) \
    ((fuzz_len = read(0, fuzz_buf, sizeof(fuzz_buf))) > 0 ? 1 : 0)
  #define __AFL_INIT() sync()
#endif

__AFL_FUZZ_INIT();

int main(int argc, char **argv) {
  unsigned char *buf;
  int len;
  
  __AFL_INIT();
  buf = __AFL_FUZZ_TESTCASE_BUF;
  
  while (__AFL_LOOP(10000)) {
    len = __AFL_FUZZ_TESTCASE_LEN;
    if (len < 1) continue;
    
    parse_json((const char *)buf, len);
  }
  
  return 0;
}
```

### 并行运行多个测试工具

```bash
# 终端 1：测试 JSON 解析
./afl-fuzz -i seeds -o output_json -M json -- ./fuzz_json

# 终端 2：测试 XML 解析
./afl-fuzz -i seeds -o output_xml -S xml -- ./fuzz_xml

# 终端 3：测试 YAML 解析
./afl-fuzz -i seeds -o output_yaml -S yaml -- ./fuzz_yaml
```

## 方法 4：使用 libfuzzer 风格的 harness

如果你的代码已经使用了 libfuzzer 风格的测试接口，可以直接使用：

```c
// fuzz_libfuzzer_style.c
#include "my_library.h"
#include <stdint.h>
#include <stddef.h>

// libfuzzer 风格的测试函数
int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  
  // 测试多个函数
  parse_json((const char *)data, size);
  parse_xml((const char *)data, size);
  parse_yaml((const char *)data, size);
  
  return 0;
}
```

### 编译

```bash
# 使用 afl-clang-fast 编译，启用 fuzzer sanitizer
./afl-clang-fast -fsanitize=fuzzer -o fuzz_target fuzz_libfuzzer_style.c -lyour_library
```

### 运行

```bash
./afl-fuzz -i seeds -o output -- ./fuzz_target
```

## 方法 5：测试整个程序的不同功能

如果你的程序本身可以接受输入，可以直接测试整个程序：

### 示例：测试一个支持多种输入格式的程序

```bash
# 测试模式 1：JSON 输入
./afl-fuzz -i seeds_json -o output_json -- ./my_program --format json @@

# 测试模式 2：XML 输入
./afl-fuzz -i seeds_xml -o output_xml -- ./my_program --format xml @@

# 测试模式 3：命令行参数
./afl-fuzz -i seeds_args -o output_args -- ./my_program --input @@
```

## 实际项目示例

### 示例 1：测试一个字符串处理库

假设你有一个字符串处理库，包含多个函数：

```c
// string_lib.h
int string_validate(const char *str, size_t len);
int string_parse(const char *str, size_t len);
int string_transform(char *str, size_t len);
```

测试工具：

```c
// fuzz_string_lib.c
#include "string_lib.h"
#include <string.h>
#include <stdlib.h>

#ifndef __AFL_FUZZ_TESTCASE_LEN
  ssize_t fuzz_len;
  unsigned char fuzz_buf[1024000];
  #define __AFL_FUZZ_TESTCASE_LEN fuzz_len
  #define __AFL_FUZZ_TESTCASE_BUF fuzz_buf
  #define __AFL_FUZZ_INIT() void sync(void);
  #define __AFL_LOOP(x) \
    ((fuzz_len = read(0, fuzz_buf, sizeof(fuzz_buf))) > 0 ? 1 : 0)
  #define __AFL_INIT() sync()
#endif

__AFL_FUZZ_INIT();

int main(int argc, char **argv) {
  unsigned char *buf;
  int len;
  char *work_buf;
  
  __AFL_INIT();
  buf = __AFL_FUZZ_TESTCASE_BUF;
  
  while (__AFL_LOOP(10000)) {
    len = __AFL_FUZZ_TESTCASE_LEN;
    if (len < 1) continue;
    
    // 测试验证函数
    string_validate((const char *)buf, len);
    
    // 测试解析函数
    string_parse((const char *)buf, len);
    
    // 测试转换函数（需要可写缓冲区）
    work_buf = malloc(len + 1);
    if (work_buf) {
      memcpy(work_buf, buf, len);
      work_buf[len] = '\0';
      string_transform(work_buf, len);
      free(work_buf);
    }
  }
  
  return 0;
}
```

### 示例 2：测试网络协议解析库

```c
// fuzz_protocol.c
#include "protocol_lib.h"

#ifndef __AFL_FUZZ_TESTCASE_LEN
  ssize_t fuzz_len;
  unsigned char fuzz_buf[1024000];
  #define __AFL_FUZZ_TESTCASE_LEN fuzz_len
  #define __AFL_FUZZ_TESTCASE_BUF fuzz_buf
  #define __AFL_FUZZ_INIT() void sync(void);
  #define __AFL_LOOP(x) \
    ((fuzz_len = read(0, fuzz_buf, sizeof(fuzz_buf))) > 0 ? 1 : 0)
  #define __AFL_INIT() sync()
#endif

__AFL_FUZZ_INIT();

int main(int argc, char **argv) {
  unsigned char *buf;
  int len;
  protocol_t *proto;
  
  __AFL_INIT();
  buf = __AFL_FUZZ_TESTCASE_BUF;
  
  while (__AFL_LOOP(10000)) {
    len = __AFL_FUZZ_TESTCASE_LEN;
    if (len < 4) continue;  // 最小协议头长度
    
    // 解析协议
    proto = parse_protocol_header(buf, len);
    if (proto) {
      process_protocol_payload(proto, buf + 4, len - 4);
      validate_protocol(proto);
      free_protocol(proto);
    }
  }
  
  return 0;
}
```

## 重要注意事项

### 1. 状态重置

在持久模式中，**必须**在每次循环迭代后重置状态：

```c
while (__AFL_LOOP(10000)) {
  // 重置全局变量
  global_state = 0;
  
  // 清理内存
  if (buffer) free(buffer);
  buffer = NULL;
  
  // 重置文件描述符
  // ...
  
  // 调用测试函数
  test_function(buf, len);
}
```

### 2. 稳定性检查

运行模糊测试后，检查 `stability` 值：

- **100%**: 完美，状态完全重置
- **< 100%**: 可能有状态泄漏，需要改进重置逻辑

### 3. 内存泄漏

使用工具检查内存泄漏：

```bash
# 使用 AddressSanitizer
./afl-cc -fsanitize=address -o fuzz_target fuzz_target.c -lyour_lib
```

### 4. 输入验证

在测试函数调用前验证输入：

```c
if (len < MIN_INPUT_SIZE) continue;
if (len > MAX_INPUT_SIZE) continue;
if (!is_valid_format(buf, len)) continue;
```

## 编译选项建议

```bash
# 基础编译
./afl-cc -o fuzz_target fuzz_target.c -lyour_lib

# 启用 AddressSanitizer（检测内存错误）
./afl-cc -fsanitize=address -o fuzz_target fuzz_target.c -lyour_lib

# 启用 UndefinedBehaviorSanitizer（检测未定义行为）
./afl-cc -fsanitize=undefined -o fuzz_target fuzz_target.c -lyour_lib

# 启用所有 sanitizer
./afl-cc -fsanitize=address,undefined -o fuzz_target fuzz_target.c -lyour_lib

# 启用代码覆盖率（用于分析）
./afl-cc -fprofile-instr-generate -fcoverage-mapping -o fuzz_target fuzz_target.c -lyour_lib
```

## 总结

1. **持久模式**是最快的方法，适合大多数场景
2. **为每个函数创建独立工具**可以获得更精细的控制
3. **测试多个函数**可以在一个工具中完成
4. **状态重置**是关键，确保每次迭代都是干净的
5. **使用 sanitizer**可以帮助发现更多问题

选择最适合你项目的方法，开始模糊测试吧！
