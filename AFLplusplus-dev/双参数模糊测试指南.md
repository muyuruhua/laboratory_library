# 双参数函数模糊测试指南

## 问题

`test-whiteBox.c` 有两个整数输入参数（X 和 Y），如何对其进行模糊测试？

## 解决方案

有几种方法可以对有两个参数的函数进行模糊测试：

### 方法 1：修改程序从文件读取（最简单）

修改程序，使用 `-f` 参数从文件读取，然后使用 `@@` 占位符。

#### 步骤 1：编译原始程序

```bash
./afl-cc -o test-whiteBox test-whiteBox.c
```

#### 步骤 2：准备种子文件

```bash
mkdir -p seeds
echo "10 20" > seeds/input1.txt
echo "-5 15" > seeds/input2.txt
echo "0 0" > seeds/input3.txt
```

#### 步骤 3：运行模糊测试

```bash
export AFL_I_DONT_CARE_ABOUT_MISSING_CRASHES=1
./afl-fuzz -i seeds -o output -- ./test-whiteBox -f @@
```

**注意**：原始程序使用 `scanf` 从标准输入读取，需要修改为从文件读取。

### 方法 2：使用修改后的版本（推荐）

我已经创建了 `test-whiteBox-fuzz.c`，它支持多种输入方式。

#### 编译

```bash
./afl-cc -o test-whiteBox-fuzz test-whiteBox-fuzz.c
```

#### 方式 A：从文件读取（文本格式）


#### 方式 B：从标准输入读取（二进制格式，更快）

```bash
# 准备种子文件（二进制格式：8 字节，前 4 字节是 X，后 4 字节是 Y）

# 创建二进制种子文件

python3 -c "import struct; open('seeds/input2.bin', 'wb').write(struct.pack('ii', -5, 15))"
python3 -c "import struct; open('seeds/input3.bin', 'wb').write(struct.pack('ii', 0, 0))"

export AFL_I_DONT_CARE_ABOUT_MISSING_CRASHES=1
./afl-fuzz -i seeds -o output -- ./test-whiteBox-fuzz
```

### 方法 3：使用持久模式（最快，推荐）

使用 `test-whiteBox-persistent.c`，速度可提升 10-20 倍。

#### 编译

```bash
./afl-cc -o test-whiteBox-persistent test-whiteBox-persistent.c
```

#### 准备种子文件（二进制格式）

```bash
mkdir -p seeds
# 使用 Python 创建二进制种子文件
python3 << EOF
import struct

# 创建几个不同的测试用例
test_cases = [
    (10, 20),      # 两个正数
    (-5, 15),     # 负数，正数
    (0, 0),       # 两个零
    (1, -1),      # 正数，负数
    (100, -100),  # 大数
]

for i, (x, y) in enumerate(test_cases, 1):
    with open(f'seeds/input{i}.bin', 'wb') as f:
        f.write(struct.pack('ii', x, y))
        print(f"创建 seeds/input{i}.bin: X={x}, Y={y}")
EOF
```

#### 运行模糊测试

```bash
export AFL_I_DONT_CARE_ABOUT_MISSING_CRASHES=1
./afl-fuzz -i seeds -o output -- ./test-whiteBox-persistent
```

## 输入格式说明

### 文本格式

文件内容为两个整数，用空格分隔：
```
10 20
```

优点：
- 人类可读
- 易于创建和调试

缺点：
- 解析较慢
- AFL++ 变异可能产生无效格式

### 二进制格式（推荐）

文件内容为 8 字节：
- 前 4 字节：X（int，32 位）
- 后 4 字节：Y（int，32 位）

创建二进制种子文件的 Python 脚本：

```python
import struct

# 创建种子文件
with open('seeds/input1.bin', 'wb') as f:
    f.write(struct.pack('ii', 10, 20))  # X=10, Y=20

with open('seeds/input2.bin', 'wb') as f:
    f.write(struct.pack('ii', -5, 15))  # X=-5, Y=15
```

或者使用命令行：

```bash
# 使用 printf 创建二进制文件
printf '\x0a\x00\x00\x00\x14\x00\x00\x00' > seeds/input1.bin  # X=10, Y=20
```

优点：
- 更快（无需解析）
- AFL++ 可以更有效地变异
- 支持所有整数值（包括负数）

缺点：
- 不可读
- 需要工具创建

## 性能对比

| 方法 | 速度 | 优点 | 缺点 |
|------|------|------|------|
| 文件输入（文本） | 慢 | 易读易调试 | 需要解析，速度慢 |
| 文件输入（二进制） | 中等 | 支持所有值 | 不可读 |
| 持久模式（二进制） | **快（10-20x）** | 最快，专业方法 | 需要修改代码 |

## 最佳实践

1. **使用持久模式**：对于可以重复调用的函数，持久模式是最快的方法
2. **使用二进制格式**：比文本格式更快，AFL++ 可以更有效地变异
3. **准备多样化的种子**：覆盖不同的输入组合
   - 正数/负数
   - 零值
   - 大数/小数
   - 边界值

## 常见问题

### Q: 为什么使用二进制格式？

A: 二进制格式更快，因为：
- 无需文本解析
- AFL++ 可以直接变异字节
- 支持所有整数值（包括负数）

### Q: 如何创建二进制种子文件？

A: 使用 Python 的 `struct` 模块：

```python
import struct
with open('seeds/input.bin', 'wb') as f:
    f.write(struct.pack('ii', X, Y))  # 两个 int
```

### Q: 持久模式中的稳定性（stability）值很低怎么办？

A: 检查是否有全局状态没有重置。在这个例子中，`test_logic` 函数是无状态的，所以稳定性应该是 100%。

### Q: 可以测试更多参数吗？

A: 可以！只需扩展输入缓冲区：
- 3 个参数：12 字节（3 个 int）
- 4 个参数：16 字节（4 个 int）
- 以此类推

## 总结

对于有两个整数参数的函数，推荐使用：
1. **持久模式**（最快）
2. **二进制格式输入**（高效）
3. **多样化的种子文件**（更好的覆盖率）

这样可以获得最佳的模糊测试性能和覆盖率。
